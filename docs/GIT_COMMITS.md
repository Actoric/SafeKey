# Коммиты и кодировка (GitHub)

## «Иероглифы» в истории

Если сообщения коммитов на GitHub отображаются как кракозябры, чаще всего текст был закоммичен в одной кодировке (например Windows-1251), а GitHub показывает как UTF-8.

**Дальше:** пишите сообщения коммитов в **UTF-8** и по возможности **на латинице** для релизов и тегов (`Release v1.2.2`, `fix: tray icon`).

## Исправить старую историю

Переписывание истории (`git rebase`, `git filter-repo`) меняет хеши — координируйте с теми, кто уже клонировал репозиторий. Для публичного репозитория проще **не трогать** старые коммиты и с новой версии соблюдать правила выше.
