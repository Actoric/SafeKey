# Руководство по тихой установке SafeKey

## Параметры командной строки установщика

Установщик SafeKey поддерживает следующие параметры командной строки:

### Тихая установка

**Параметр:** `/S` или `/SILENT`

Устанавливает программу без показа окон установщика.

**Пример:**
```cmd
SafeKey-Setup-x64.exe /S
```

### Выбор директории установки

**Параметр:** `/D=путь`

Указывает директорию для установки программы. **Важно:** параметр `/D` должен быть последним в командной строке.

**Пример:**
```cmd
SafeKey-Setup-x64.exe /S /D=C:\Program Files\SafeKey
```

### Комбинированное использование

**Тихая установка с выбором директории:**
```cmd
SafeKey-Setup-x64.exe /S /D=C:\MyApps\SafeKey
```

**Обычная установка с выбором директории:**
```cmd
SafeKey-Setup-x64.exe /D=C:\MyApps\SafeKey
```

## Что происходит при тихой установке

1. ✅ Программа устанавливается без показа окон
2. ✅ Создается ярлык на рабочем столе (если не отключен)
3. ✅ Создается ярлык в меню "Пуск"
4. ✅ Программа автоматически запускается после установки

## Примеры использования

### Установка в стандартную директорию (тихая)
```cmd
SafeKey-Setup-x64.exe /S
```

### Установка в пользовательскую директорию (тихая)
```cmd
SafeKey-Setup-x64.exe /S /D=C:\Users\%USERNAME%\AppData\Local\SafeKey
```

### Установка в системную директорию (тихая)
```cmd
SafeKey-Setup-x64.exe /S /D=C:\Program Files\SafeKey
```

### Установка через PowerShell
```powershell
Start-Process -FilePath ".\SafeKey-Setup-x64.exe" -ArgumentList "/S", "/D=C:\Program Files\SafeKey" -Wait
```

### Установка через cmd с ожиданием завершения
```cmd
SafeKey-Setup-x64.exe /S /D=C:\Program Files\SafeKey
```

## Примечания

- Параметр `/D` должен быть последним в командной строке
- При тихой установке программа автоматически запускается после завершения установки
- Ярлык на рабочем столе создается автоматически
- Для установки в системные директории может потребоваться права администратора

## Коды возврата

- `0` - Успешная установка
- `1` - Ошибка установки
- `2` - Установка отменена пользователем (не применимо для тихой установки)
