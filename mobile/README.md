# SafeKey — мобильное приложение

Мобильная версия SafeKey с теми же данными в облаке (Яндекс.Диск). Пароли, категории, резервные коды и контрольные вопросы синхронизируются с десктопным приложением.

## Требования

- **Сначала выполните синхронизацию с десктопа** — в настройках десктопного SafeKey подключите Яндекс.Диск и нажмите «Синхронизировать». В облако загружаются зашифрованная база и ключевой файл (для входа по мастер-паролю на мобильном).
- В [настройках OAuth-приложения Яндекса](https://oauth.yandex.ru/) добавьте **redirect URI** для мобильного приложения:  
  `com.safekey.app://oauth`  
  (чтобы после авторизации открывалось приложение, а не страница с кодом).

## Сборка на ПК и установка на телефон (Android)

Собрать APK можно на компьютере, затем перенести файл на телефон и установить.

1. **Один раз** добавьте платформу Android (если ещё не добавляли):

```bash
cd mobile
npm install
npx cap add android
```

2. **Сборка APK** (на ПК):

```bash
npm run build:android
```

Скрипт сам соберёт веб-часть, синхронизирует с Android-проектом и запустит сборку release APK. Готовый файл появится в каталоге `android/app/build/outputs/apk/release/` (или укажет путь в консоли). Перенесите APK на телефон и установите.

Альтернатива: после `npm run cap:sync` откройте проект в Android Studio (`npx cap open android`) и соберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

> **iOS**: сборка для iPhone/iPad возможна только на macOS в Xcode. На Windows можно собирать только Android.

## Обычный запуск (для разработки)

```bash
npm run build
npx cap sync
npx cap open android   # или: npx cap open ios
```

В Android Studio / Xcode запустите приложение на устройстве или эмуляторе.

## Адаптивный интерфейс

Интерфейс подстраивается под любой размер экрана: телефон (портрет/ландшафт), планшет, узкие и широкие дисплеи. Используются безопасные отступы (вырезы, жесты), масштабируемые шрифты и отступы, на широких экранах карточки паролей отображаются сеткой.

## Разработка в браузере

```bash
npm run dev
```

Откройте http://localhost:5174. Восстановление из облака по OAuth в браузере будет работать только если настроить redirect (например, через localhost или тестовый URL).

## Функции

- **Вход**: по мастер-паролю (если хранилище уже есть на устройстве) или восстановление из облака (Яндекс.Диск).
- **Пароли**: просмотр по категориям, копирование логина и пароля.
- **Синхронизация**: кнопка «Синхронизировать» отправляет текущую базу в облако (тот же файл, что и десктоп).

Резервные коды и контрольные вопросы доступны через тот же API; при необходимости их можно добавить на экраны мобильного приложения.
