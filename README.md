# SafeKey - Менеджер паролей

Кроссплатформенное настольное приложение для безопасного хранения и управления паролями с автоматическим обновлением и облачной синхронизацией.

## ✨ Основные функции

- 🔐 **AES-256 шифрование** всех данных
- 📁 **Структурированное хранение** с категориями (раскладками) - до 3 уровней вложенности
- 🔍 **Быстрый поиск** и фильтрация паролей
- ⌨️ **Системный оверлей** с настраиваемыми горячими клавишами
- ☁️ **Облачная синхронизация** с Яндекс.Диском и Google Drive (OAuth авторизация)
- 🔄 **Автоматические обновления** через GitHub Releases
- 🎨 **Современный интерфейс** с поддержкой локализации
- 🔑 **Генератор паролей** с настраиваемыми параметрами
- 📝 **Резервные коды** для двухфакторной аутентификации
- ❓ **Контрольные вопросы** для восстановления доступа
- 🔒 **Windows PIN авторизация** (альтернатива мастер-паролю)
- 📋 **Быстрое копирование** паролей, логинов и URL
- ⭐ **Избранное** для быстрого доступа к часто используемым паролям
- 🎯 **Автозапуск** и работа в системном трее

## 🚀 Быстрый старт

### Первый запуск

1. **Создание мастер-пароля**: При первом запуске создайте надежный мастер-пароль (минимум 8 символов)
2. **Альтернатива**: Используйте Windows PIN для авторизации (если доступно)
3. **Добавление паролей**: Нажмите "Новый пароль" в боковой панели
4. **Быстрый доступ**: Используйте `Ctrl+Shift+P` для открытия оверлея поиска

## 🎯 Основные возможности

### Управление паролями

- **Добавление**: Нажмите "Новый пароль" и заполните форму
- **Редактирование**: Выберите пароль из списка и нажмите "Редактировать"
- **Удаление**: Выберите пароль и нажмите "Удалить" (с подтверждением)
- **Копирование**: Быстрое копирование пароля, логина или URL одной кнопкой
- **Поиск**: Используйте поисковую строку для быстрого поиска по названию, логину или URL

### Категории (Раскладки)

- **Создание**: Нажмите "Создать раскладку" в боковой панели
- **Вложенность**: Поддерживается до 3 уровней вложенности
- **Удаление**: Нажмите на кнопку удаления рядом с названием раскладки
- **Фильтрация**: Выберите раскладку для фильтрации паролей

### Генератор паролей

- Настраиваемая длина (8-64 символа)
- Включение/исключение заглавных букв, цифр, специальных символов
- Исключение похожих символов (0, O, l, I, 1)
- Быстрое копирование сгенерированного пароля

### Облачная синхронизация

#### Яндекс.Диск
- OAuth авторизация через встроенный браузер
- Настраиваемый путь на диске
- Автоматическая синхронизация при сохранении паролей

#### Google Drive
- OAuth авторизация через Google Cloud Console
- Настраиваемый ID папки
- Автоматическая синхронизация при сохранении паролей

### Системный оверлей

- **Горячая клавиша**: По умолчанию `Ctrl+Shift+P` (настраивается)
- **Быстрый поиск**: Откройте оверлей и начните вводить название сервиса
- **Копирование**: Одна кнопка для копирования пароля
- **Автозакрытие**: Оверлей закрывается при потере фокуса

### Автоматические обновления

- Проверка обновлений при запуске
- Уведомления о доступных обновлениях
- Автоматическая загрузка и установка
- Обновления через GitHub Releases

### Резервные коды и контрольные вопросы

- Хранение резервных кодов для двухфакторной аутентификации
- Сохранение контрольных вопросов для восстановления доступа
- Полное шифрование всех данных

## 🔒 Безопасность

- Все данные шифруются с помощью **AES-256** перед сохранением
- Мастер-пароль используется для генерации ключа шифрования через **PBKDF2** (10000 итераций)
- Данные остаются зашифрованными на вашем компьютере
- Без мастер-пароля данные невозможно расшифровать
- Поддержка Windows PIN как альтернативного метода авторизации
