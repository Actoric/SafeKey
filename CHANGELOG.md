# Changelog

## [Версия X.X.X] - 2024

### Новые возможности:
- ✨ Упрощенный оверлей с прозрачным фоном - теперь оверлей не имеет белого фона и полностью прозрачен
- ✨ Ограничение отображения паролей в оверлее - показывается до 4 паролей с возможностью прокрутки для просмотра остальных
- ✨ Улучшенный интерфейс оверлея - только поисковая строка и компактный список паролей

### ✨ Улучшения:
- 🎨 Убран белый фон за оверлеем - теперь оверлей полностью прозрачен и не перекрывает рабочий стол
- 🎨 Упрощен визуальный дизайн оверлея - темная полупрозрачная панель с размытием
- 🔧 Убраны настройки из раскладок - удалена кнопка с шестеренкой, упрощен интерфейс управления раскладками
- 🔧 Улучшена производительность оверлея - оптимизирована загрузка и отображение паролей
- 🔧 Улучшена работа скроллбара в оверлее - добавлены стили для более удобной навигации
- 🐛 Исправлено определение активного приложения - улучшена точность определения активного окна в Windows
- 🐛 Исправлена фильтрация паролей в оверлее - теперь все пароли отображаются корректно

### Технические изменения:
- Упрощена логика фильтрации паролей в оверлее
- Удалена функциональность привязки паролей к приложениям
- Оптимизированы стили оверлея для лучшей производительности
- Улучшена обработка прозрачности окна оверлея
