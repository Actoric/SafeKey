# Инструкция по исправлению проблемы с иконкой

## Проблема
Иконка видна в свойствах exe файла, но Windows показывает белый лист документа в меню Пуск, панели задач и диспетчере задач.

## Причина
Иконка не содержит всех необходимых размеров или имеет неправильный формат.

## Решение

### 1. Создайте правильную иконку

Иконка должна содержать ВСЕ следующие размеры:
- 16x16 пикселей
- 32x32 пикселя
- 48x48 пикселей
- 256x256 пикселей

### 2. Инструменты для создания иконки

**Онлайн инструменты:**
- https://convertio.co/ru/png-ico/ - конвертер PNG в ICO с несколькими размерами
- https://www.icoconverter.com/ - создание ICO с несколькими размерами
- https://www.favicon-generator.org/ - генератор иконок

**Десктопные инструменты:**
- IcoFX (бесплатный) - https://icofx.ro/
- GIMP (бесплатный) - с плагином для экспорта ICO
- Photoshop - с плагином для экспорта ICO

### 3. Шаги создания правильной иконки

1. Подготовьте исходное изображение в высоком разрешении (минимум 256x256)
2. Создайте версии всех размеров: 16x16, 32x32, 48x48, 256x256
3. Используйте инструмент для создания ICO файла со ВСЕМИ размерами
4. Сохраните как `build/icon.ico`
5. Пересоберите приложение

### 4. Проверка иконки

После создания иконки проверьте:
1. Откройте `build/icon.ico` в проводнике Windows
2. Иконка должна отображаться правильно
3. Если виден белый лист - иконка неправильная

### 5. После пересборки

1. Удалите старую версию приложения
2. Очистите кэш иконок Windows:
   ```powershell
   taskkill /f /im explorer.exe
   del /a /q "%localappdata%\IconCache.db"
   start explorer.exe
   ```
3. Установите новую версию
4. Перезагрузите компьютер

## Альтернативное решение

Если проблема сохраняется, попробуйте:
1. Использовать другой инструмент для создания иконки
2. Убедиться, что иконка не повреждена
3. Попробовать создать иконку заново из исходного изображения

## Проблемы с конфигурацией electron-builder

Если все размеры иконки правильные, но проблема сохраняется, возможно, electron-builder не встраивает иконку корректно.

### Текущая конфигурация

В `package.json` иконка указана в двух местах:
1. В корневой секции `build`: `"icon": "build/icon.ico"`
2. В секции `win`: `"icon": "build/icon.ico"`

### Альтернативные подходы к конфигурации

#### Вариант 1: Использование пути относительно buildResources

Если `buildResources` установлен в `"build"`, можно попробовать указать путь относительно этой папки:

```json
"win": {
  "icon": "icon.ico"  // без префикса build/
}
```

#### Вариант 2: Использование только корневой иконки

Удалите `"icon"` из секции `win` и оставьте только в корневой секции `build`:

```json
"build": {
  "icon": "build/icon.ico",
  "win": {
    // без "icon" здесь
  }
}
```

#### Вариант 3: Использование абсолютного пути

Попробуйте указать абсолютный путь (относительно корня проекта):

```json
"win": {
  "icon": "./build/icon.ico"
}
```

#### Вариант 4: Перемещение иконки в корень проекта

1. Скопируйте `build/icon.ico` в корень проекта
2. Измените конфигурацию:
```json
"win": {
  "icon": "icon.ico"
}
```
3. Обновите `buildResources`:
```json
"directories": {
  "buildResources": "."
}
```

#### Вариант 5: Использование ресурсов Windows

Создайте файл ресурсов Windows (`.rc`) и скомпилируйте его:

1. Создайте `build/icon.rc`:
```
IDI_ICON1 ICON "icon.ico"
```

2. Добавьте в конфигурацию:
```json
"win": {
  "icon": "build/icon.ico",
  "extraResources": [
    {
      "from": "build/icon.rc",
      "to": "."
    }
  ]
}
```

### Проверка после изменений

1. Удалите папку `release` и `dist`
2. Выполните полную пересборку:
   ```bash
   npm run build
   npm run build:win
   ```
3. Проверьте сгенерированный exe файл в `release/win-unpacked/SafeKey.exe`
4. Откройте свойства exe файла и проверьте вкладку "Подробности" - должна быть видна иконка
5. Очистите кэш иконок Windows (см. раздел 5 выше)

### Отладка electron-builder

Для получения подробной информации о процессе сборки:

```bash
DEBUG=electron-builder npm run build:win
```

Или на Windows:
```powershell
$env:DEBUG="electron-builder"; npm run build:win
```

Это покажет, где electron-builder ищет иконку и как он её обрабатывает.
