# SafeKey v1.1.8 - Новые возможности и улучшения

## 🆕 Новые возможности

### Импорт паролей
- **Импорт из TXT файлов** - возможность импортировать пароли из текстовых файлов в формате `сервис:логин:пароль` или `сервис:пароль`
- **Импорт из CSV (Яндекс)** - поддержка импорта паролей из CSV файлов Яндекс.Паролей с автоматическим определением формата
- **Автоматическое создание категорий** - при импорте создается новая раскладка (категория) с указанным названием для удобной организации импортированных паролей
- **Прогресс-бар импорта** - визуальное отображение процесса импорта с показом количества импортированных паролей (X из Y)
- **Умное определение названий** - для CSV файлов используется первое поле (сайт/URL) как название пароля

### Множественное удаление паролей
- **Режим выбора** - возможность выбрать несколько паролей для одновременного удаления
- **Чекбоксы для выбора** - удобный интерфейс с чекбоксами для выбора нужных паролей
- **Выбрать все / Снять выделение** - быстрая операция для выбора всех паролей в списке
- **Счетчик выбранных** - отображение количества выбранных паролей в заголовке списка
- **Диалог подтверждения** - стилизованное окно подтверждения удаления в едином стиле приложения

### Синхронизация с облаком
- **Прогресс-бар синхронизации** - визуальное отображение процесса синхронизации с облаком справа внизу экрана
- **Автоматическое отображение** - прогресс-бар появляется только во время активной синхронизации
- **Процент выполнения** - отображение процента завершения синхронизации с синей полосой прогресса

## ✨ Улучшения

### Интерфейс и дизайн
- **Единый цвет кнопок** - кнопки "Добавить резервные коды" и "Добавить контрольные вопросы" теперь используют основной синий цвет приложения
- **Toggle switches в настройках** - замена чекбоксов на современные переключатели с анимацией:
  - Серый круглый переключатель, который перемещается влево/вправо
  - Синий фон и линия при включении
  - Плавная анимация переключения
  - Идеальное выравнивание с текстом
- **Диалог удаления паролей** - новый стилизованный диалог подтверждения удаления в едином стиле приложения:
  - Иконка корзины в заголовке
  - Поддержка одиночного и множественного удаления
  - Отображение количества удаляемых паролей
  - Кнопка закрытия и красивое оформление

### Импорт и экспорт
- **Диалог ввода названия** - перед импортом запрашивается название для создаваемой категории
- **Автоматическая организация** - все импортированные пароли автоматически помещаются в созданную категорию
- **Улучшенный парсинг CSV** - корректная обработка формата Яндекс.Паролей с извлечением названий из URL
- **Валидация данных** - проверка формата файла и корректности данных перед импортом

### Производительность и стабильность
- **Исправление бага с раскладками** - раскладки теперь корректно отображаются сразу после импорта паролей
- **Обновление категорий** - автоматическое обновление списка категорий после создания новой раскладки при импорте
- **Фоновая синхронизация** - синхронизация с облаком после импорта происходит в фоновом режиме без блокировки интерфейса
- **Оптимизация импорта** - добавлены задержки между импортом паролей для предотвращения проблем с производительностью

### Удобство использования
- **Визуальная обратная связь** - прогресс-бары для всех длительных операций (импорт, синхронизация)
- **Информативные сообщения** - показ количества импортированных паролей и статуса операций
- **Улучшенная навигация** - быстрый доступ к режиму множественного выбора через иконку в заголовке списка
- **Интуитивный интерфейс** - понятные иконки и подсказки для всех новых функций
